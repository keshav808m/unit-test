🧪 AI Unit Test Agent
A full-stack AI tool that autonomously generates robust, ready-to-run unit tests for your code.
It supports multiple languages (Python, JavaScript, Java, C++) and uses Google Gemini 2.5 Flash to ensure high code coverage and edge-case handling.

🚀 Features
Multi-Language Support: Generates tests for Python (Pytest), JavaScript (Jest), Java (JUnit), and C++ (GoogleTest).

Smart Analysis: Identifies edge cases, null checks, and boundary values automatically.

Modern UI: Dark-themed, split-screen code editor using Monaco Editor (VS Code's engine).

One-Click Copy: Easily copy generated tests to your clipboard.

Fast & Free: Powered by Google's Gemini Flash model (Free Tier compatible).

🛠️ Tech Stack
Frontend: React (Vite), Monaco Editor, Axios.

Backend: Python (FastAPI), Uvicorn.

AI Engine: Google Gemini (via langchain-google-genai).

Styling: CSS3 (VS Code Dark Theme).

⚙️ Prerequisites
Node.js (v16 or higher)

Python (v3.9 or higher)

Google Gemini API Key
